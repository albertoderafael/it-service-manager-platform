# Fuente de la guía de aprendizaje

Ficheros con los que se genera `guia-frontend-it-service-manager.pdf`.

- `src/*.md`: capítulos en Markdown (convenciones al principio de `build.py`).
- `style.css`: diseño de página.
- `build.py`: genera el PDF con WeasyPrint (`pip install weasyprint markdown pygments`; `python build.py`).
- `check_links.py`: comprueba que todos los enlaces internos del PDF tienen destino.

Guía completa (26 capítulos y 5 anexos) terminada el 24-10-2026.
